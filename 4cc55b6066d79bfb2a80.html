📤 Отправить статью в Telegram

Сообщение формируется так же, как при автоматической рассылке: заголовок, анонс, ссылка на статью и подписка на канал. Отправка идёт напрямую в Bot API из вашего браузера.

🎬 Сделать ролики по статьям

Генерация идёт в GitHub Actions (ffmpeg + озвучка в облаке, 1–2 мин на статью). Готовые ролики автоматически коммитятся в репозиторий и становятся доступны по прямым ссылкам сайта через 1–2 минуты (деплой Pages) — после этого их можно публиковать в YouTube/Instagram в блоке ниже. Архив для скачивания дублируется в Artifacts запуска.

📤 Публикация в YouTube и Instagram

Выберите статью — ролик для неё должен быть уже сгенерирован (см. блок выше). Видео публикуется из публичной ссылки сайта.

▶️ YouTube

Кнопка «Авторизовать» откроет Google — разрешите доступ, после чего скрипт сам получит refresh token (сохраняется в вашем браузере). Готовый refresh token можно и вставить вручную в поле выше. «Проверить доступ» — проверит, что авторизация работает (покажет название канала). Нужна включённая YouTube Data API v3 и scope youtube.upload.

📸 Instagram (Reels)

Нужен business/creator аккаунт, связанный со страницей Facebook, и токен с правами instagram_content_publish (обычно получают в Meta Graph API Explorer или через обмен short-lived → long-lived).

## Формат сайта (07.08.2026)
- **Одностраничник** (лендинг + блог на главной)
- Рубрики: Новые модели, Электромобили, Двигатели, История марок, Мировые новости
- Подписка на еженедельный дайджест (e-mail сохраняется в localStorage `ap_subscribers`)
- **Ежедневная ротация статей**: в `script.js` есть банк `ARTICLE_BANK` (28 статей). Каждый день на главной показываются 6 «свежих» статей с датами (сегодня/вчера/...). Добавление статьи = добавить объект в `ARTICLE_BANK`.

1. Наполнить банк статей до 30-50 шт. (контент — главный фактор)
2. Каждый день добавлять новую статью в `ARTICLE_BANK`
3. Переобход: Яндекс.Вебмастер + Search Console (проверить индексацию)
4. Собирать подписчиков через форму (e-mail в localStorage)
5. Публиковать анонсы в соцсетях/Telegram для внешнего трафика
6. Когда будет трафик — выбирать монетизацию (реклама/партнёрка/Telegram)

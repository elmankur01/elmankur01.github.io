Экспорт data.js

Скачайте обновлённый файл и закоммитьте его в репозиторий

После изменений в каталоге или магазинах скачайте data.js и замените им файл в проекте. Затем закоммитьте и запушьте — сайт обновится автоматически.

Как обновить сайт:

  1. Скачайте data.js выше
  2. Замените файл data.js в папке auto-parts/
  3. Выполните: git add data.js && git commit -m "update catalog" && git push
  4. GitHub Pages обновит сайт автоматически
